Limits and test obligations

Production authenticity requires independent issuer trust, secure key custody, anti-replay storage, external ledger checkpoints, interoperability design, real resource-owner consent and security review. This lab supplies none of those guarantees.

HTML is single-file, but the Python/WebAssembly interpreter is downloaded at runtime from the pinned Pyodide version. Once loaded, calculations and state stay in-browser. Offline reload is not guaranteed without separately caching the runtime.
